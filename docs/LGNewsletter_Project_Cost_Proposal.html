Project Overview

LG Newsletter is a CodeIgniter-based system that provides end‑to‑end newsletter management, subscriber lifecycle handling, campaign sending, and a comprehensive admin panel. It also integrates rich content and mobile‑friendly API endpoints to support broader church media needs.

Core Features

  • Newsletter Creation & Campaigns: Compose via TinyMCE, preview, drafts, scheduling, send to confirmed subscribers, campaign history.
  • Subscriber Management: Public subscription with email confirmation; statuses: pending, confirmed, unsubscribed; dashboard with search and management.
  • Bulk Operations: Import/export subscriber lists; batch resend confirmations; bulk deletions.
  • Email Delivery: SMTP configuration, confirmation and welcome emails, CID‑embedded logo, email history logging.
  • Unsubscribe Flow: One‑click unsubscribe with reason capture and audit trail.
  • Admin Panel: Secure login, user management, role management, system settings (SMTP, FCM), dashboard with key metrics.

Additional Modules

  • Content: Audio, Video, Music, Books & Book Categories, Articles/Ebooks, Devotionals, News.
  • Taxonomy: Categories and Subcategories; Branches.
  • Events & Live: Events, Livestreams, Radios.
  • Community: Comments, Replies, moderation (publish/unpublish, reports).
  • Inbox & Notifications: Inbox messaging, FCM push notifications, system notifications.
  • Bible & Hymns: Bible endpoint and hymn resources.
  • Payments: Payment integrations including Stripe and PayPal link generation.
  • Mobile/REST API: Discovery/home data, categories, search, media endpoints (download/trending/likes), devotionals, events, streams, radios, authentication/login.
  • Newsletter API: Public endpoints for subscribe and confirm with JSON responses.
  • System Setup: Installation helpers, settings configuration, public newsletter page.

Deliverables

  • Configured newsletter platform with subscriber management and campaigns.
  • Admin interface for content, users, and settings.
  • Public subscription pages and confirmation flow.
  • REST API endpoints for mobile integration.
  • Deployment assistance and basic handover documentation.
